## 🐍 Programação para Automação de Tarefas em Python

Aprenda a usar **Python** para automatizar tarefas repetitivas em topografia:

- Manipulação de arquivos CSV/PNEZD
- Geração de relatórios automáticos
- Integração com bibliotecas geoespaciais (Shapely, Fiona, Pyproj)
- Scripts de processamento em lote

## 🏴 LISP

**LISP** é a linguagem de automação nativa do AutoCAD. Usada para:

- Criar comandos customizados
- Automatizar workflows de levantamento
- Processar pontos e desenhos em lote

- Filtros e classificações
