Objetivos da aula

1. Estruturar Dados

Compreender a relação entre dados topográficos brutos, contratos de dados (CSV) e entidades CAD/SIG.

2. Automatizar Tarefas

Identificar atividades repetitivas e aplicar scripts para criar pontos, linhas, polígonos, textos e cotas automaticamente.

3. Integrar Ferramentas

Utilizar AutoLISP, Python e QGIS para processar dados geoespaciais e gerar plantas e memoriais.

4. Controlar Qualidade

Identificar erros e inconsistências nos dados antes da geração do desenho, desenvolvendo fluxos reproduzíveis.
