Exercício prático em duplas

Roteiro de Execução

  1. Receber o arquivo PONTOS.csv.
  2. Validar os dados (identificar erros e duplicidades).
  3. Importar os pontos para o ambiente escolhido (CAD, QGIS ou Python).
  4. Criar layers automaticamente conforme o código.
  5. Gerar textos (ID, cota, descrição) e símbolos.
  6. Calcular distâncias e azimutes (se houver conectividade).
  7. Exportar os resultados.

1. Planta Topográfica

planta.dxf (com layers e textos organizados)

2. Tabela de Coordenadas

coordenadas.xlsx (com metadados e CRS)

3. Visualização Geográfica

pontos.kml (transformado para WGS84)

4. Documentação

relatorio_validacao.txt (erros encontrados)
