## 🛠️ Conceitos-chave para entender a automação

Esta seção introduz os **conceitos fundamentais** para entender como funciona a automação em levantamentos topográficos:

- Evolução dos métodos de medição
- Integração hardware + software
- Workflows de campo
- Exportação de dados
- Interoperabilidade entre sistemas

As atividades da disciplina são tipicamente avaliadas por:

- **Projetos práticos** (levantamento real + processamento)
- **Exercícios computacionais** (scripts, planilhas, simulações)
