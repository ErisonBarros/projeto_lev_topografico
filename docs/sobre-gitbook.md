# 📖 Sobre o GitBook

> O GitBook é o **portal principal do aluno** desta disciplina.

---

## 🎯 O que é?

[GitBook](https://www.gitbook.com/) é uma plataforma de documentação moderna, com interface amigável, navegação intuitiva, busca integrada e suporte a Markdown. É onde os alunos acessam o conteúdo da disciplina para estudo e consulta.

## 🌐 Acesso

🔗 **https://erisonbarros.gitbook.io/projeto-de-levantamento-topografico/**

## ✨ Funcionalidades

- 📖 **Leitura navegável** com sumário lateral
- 🔍 **Busca integrada** em todo o conteúdo
- 🌙 **Modo noturno** para leitura confortável
- 📱 **Responsivo** (desktop, tablet, celular)
- 🔗 **Links diretos** para seções específicas
- 📥 **Exportar para PDF** (páginas individuais)

## 🔄 Sincronização

O conteúdo do GitBook é **gerado a partir do repositório GitHub**:

```text
GitHub (Markdown) ──► GitBook (interface web)
```

- ✅ **GitHub é a fonte oficial** de toda a verdade
- ✅ Toda alteração no GitHub propaga para o GitBook (via integração)
- ✅ Histórico de versões preservado no Git (GitBook lê o estado atual)
- ❌ Edições diretas no GitBook **não** são refletidas no GitHub

## 📚 Estrutura

A navegação do GitBook é definida pelo arquivo [`packages/api/SUMMARY.md`](https://github.com/ErisonBarros/projeto_lev_topografico/blob/erison.barros/packages/api/SUMMARY.md) no repositório.

Seções principais:

- 👋 **Boas-vindas**
- 📋 **Ementa da Disciplina** — temas centrais
- 🔧 **Manuais e Instalação** — equipamentos
- 🎓 **Aulas** — teóricas e práticas
- 📐 **Atividades** — exercícios e trabalhos
- 📚 **Material Didático** — tutoriais, guias
- 🔗 **Links Externos** — LABAT, GitHub

## 🆚 Comparação com este site (MkDocs)

| aspecto | GitBook | GitHub Pages (MkDocs) |
|---|---|---|
| público-alvo | aluno (leitura) | público geral (apresentação institucional) |
| conteúdo | didático completo | resumo institucional + links |
| editor | GUI ou Markdown | Markdown via Git |
| busca | sim (proprietária) | sim (Material Search) |
| customização | limitada | total (Material for MkDocs) |
| offline | PDF por seção | site completo |
| versionamento | parcial | total (Git) |
