# Planejamento de Obra de Levantamento Topográfico

Esta aula apresenta o planejamento de uma obra de levantamento topográfico como um processo integrado de engenharia: definição do problema, especificação do escopo, reconhecimento da área, projeto da rede de apoio, escolha metodológica, organização da equipe, segurança, execução, controle de qualidade, processamento e entrega.

## Objetivos de aprendizagem

Ao final do estudo, o aluno deverá ser capaz de relacionar a finalidade de um levantamento aos produtos necessários, justificar a escolha de métodos e equipamentos, organizar uma mobilização de campo, definir verificações de qualidade e estruturar uma documentação técnica rastreável.

## Mensagem central

> Planejar antes de medir é proteger a qualidade, o prazo e a segurança da obra.

## Aplicação no projeto integrador

As equipes devem utilizar este roteiro para elaborar um plano de levantamento executável para uma área real, indicando objetivo, limite da área, referência, precisão, método, equipe, logística, riscos, controles, produtos e critérios de aceitação.
