# Instalar a Base



***

**Etapa 1: Preparação Inicial (Abrir/Criar Projeto)**

1. **Abra um Projeto Existente ou Crie um Novo:**
   * No software da coletora HCE 320, vá para "Projetos" e selecione "Abrir" um projeto existente ou "Novo" para criar um.
   * Se for criar um novo, insira o nome do projeto (ex: "RCS Teste") e outras informações básicas (usuário, data, fuso horário) que geralmente permanecem inalteradas.

***

**Etapa 2: Conexão da Base Pela Primeira Vez em um Local Específico**

* Esta seção descreve como configurar a base de maneira correta na **primeira vez** que você a estação em um local específico do projeto.

1. **Conecte o Equipamento Base:**
   * Após criar ou abrir o projeto, o sistema solicitará a conexão da sua base RTK (ex: CHC 250).
   * Aguarde a conexão ser estabelecida com sucesso. O sistema pode indicar "autônomo" inicialmente, especialmente se estiver em um local fechado.
2. **Acesse o Modo de Trabalho da Base:**
   * Depois de conectado, selecione o "Modo de Trabalho" e escolha a opção **"Base"**.
   * Aceite o formato.
3. **Configurar a Base (Primeira Vez - Crucial para evitar duplicações):**
   * **NÃO selecione "obter por número"** neste ponto, pois isso fará com que o sistema salve a base de forma que "vai ficar várias bases".
   * Em vez disso, selecione a opção **"inserir manualmente"**.
   * Dê um "OK".
   * **Nomeie a Base:** Insira um nome claro para sua base (ex: "Base 1", "Base 2", etc., conforme a sua organização). Essa prática de nomeação ajuda a gerenciar suas bases posteriormente.
   * Dê outro "OK" para finalizar a configuração.
4. **Verifique a Base Cadastrada:**
   * Vá para "Levantamento de Pontos" e, em seguida, para "Gestor de Pontos".
   * Você deverá ver a base que acabou de cadastrar com a data e hora corretas, como "18 horas 26 minutos e 13 segundos do dia 10/11".
5. **Inicie o Levantamento:**
   * Com a base configurada corretamente, você pode iniciar o seu levantamento normalmente.

***

**Etapa 3: Reconexão à MESMA Base em Outro Momento (Evitando Novas Bases)**

* Esta seção é fundamental para **evitar a criação de bases repetidas** quando você retorna para o **mesma localização física** da base, seja "no outro dia ou então logo depois do almoço".

1. **Reabra o Projeto e Reconecte a Base:**
   * Feche o projeto se necessário e reabra-o (como se estivesse retornando para continuar o trabalho).
   * Reconecte o equipamento base.
2. **Acesse o Modo de Trabalho da Base Novamente:**
   * Assim que a conexão for estabelecida, selecione "Modo de Trabalho" e, em seguida, **"Base"**.
   * Aceite o formato.
3. **Reutilize a Base Existente (Passo Chave):**
   * **NÃO selecione "obter por número"** novamente. A base já existe e está registrada.
   * Selecione **"inserir manualmente"**.
   * **Clique nos "três pontinhos"** para abrir a lista de bases já cadastradas no seu projeto.
   * **Selecione a base que você já havia cadastrado** para aquele local (ex: "Base 1").
   * Dê um "OK".
4. **Confirmação do Sistema:**
   * O sistema irá reconhecer que "a base de um já existe". Isso é um bom sinal de que ele não criará uma nova entrada.
5. **Verifique a Não Criação de Nova Base:**
   * Acesse "Levantamento de Pontos" e "Gestor de Pontos" novamente.
   * Você deverá observar que **"ele não criou outra base"**. Em vez disso, o sistema reconheceu que "ele foi estacionado na mesma base". Isso é a confirmação de que você evitou a duplicação.
6. **Continue o Levantamento:**
   * Agora você pode continuar seu levantamento usando a base existente, mantendo o projeto organizado.

***

**Observação Importante sobre Criação de Novas Bases:**

* **Somente crie uma NOVA BASE quando você REALMENTE mover o equipamento para um "outro local" físico**.
* Enquanto você estiver trabalhando na mesma posição física da base, **não há necessidade de "ficar salvando repetidamente"**. Seguir este fluxo de trabalho evitará que seu levantamento fique "enchendo o nosso levantamento de bases repetidas".
