🎯 Sobre a disciplina

Repositório oficial da disciplina Projeto de Levantamento Topográfico do curso de Engenharia Cartográfica da UFPE, mantido pelo Laboratório de Automação Topográfica (LABAT).

O conteúdo inclui ementa, aulas teóricas e práticas, atividades, manuais de equipamentos, material didático complementar e skills acadêmicas — todo em Markdown, versionado no GitHub.

🌐 Plataformas do curso

  • 📚 GitBook — portal principal do aluno (leitura navegável)
  • 💾 GitHub — repositório versionado + Issues + Pull Requests
  • 🌎 GitHub Pages — este site público institucional
  • 🔬 LABAT Google Sites — pesquisa, extensão e projetos

Acessar GitBook Repositório no GitHub

📂 Conteúdo em destaque

Ementa: drones topográficos, estações totais robóticas, estação total Geodetic GD2i-8 (4 aulas práticas), processamento GNSS, processamento estático rápido.

Aulas: planejamento de obra topográfica, introdução ao LandXML, comandos do AutoCAD para topografia, configurações no CAD.

Material didático: Python para automação, AutoCAD + ChatGPT, LISP, PyQGIS, expressões no QGIS.

🤝 Como contribuir

  1. Fork este repositório
  2. Crie uma branch descritiva (feature/nova-aula-gps, fix/correcao-aula-3)
  3. Faça suas alterações em arquivos .md
  4. Abra um Pull Request com descrição clara
